All 524 catalog items, in alphabetical order by title. Each edition or console version has its own row and permanent item ID.

## How to record decisions

1. Sign in to GitHub with repository write access and use the pencil (Edit) button on this file.
2. Replace `Unreviewed` in the Decision column with exactly one of `Keep`, `Sell`, or `SPG`.
3. Click **Commit changes** to save your decisions to the repository. You can work in batches and return later.

**Keep** = owner keeps the item. **Sell** = owner sells personally. **SPG** = sell through SavePoint Gaming. **Unreviewed** = no decision recorded yet.

This is a Markdown document; the rendered table is not an interactive form. Decisions are recorded only when edits are committed. Repository edits are public. No decisions have been assumed or copied from browser-only storage. Once finished, send this file or its GitHub link to the site editor to update the storefront.
